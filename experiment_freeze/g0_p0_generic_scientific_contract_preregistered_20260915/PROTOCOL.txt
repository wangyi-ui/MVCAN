======================================================================

Q_t
-> relation state R_t
-> utility-conditioned semantic action A(T_relation, U_cycle)

======================================================================
5. DIRECTIONAL ACTION-SPACE DEFINITION
======================================================================

Let:

Vset = {0, ..., V-1}

Every directional action s is an ordered pair:

a_s = (G_s, H_s)

with:

G_s intersection H_s = empty
G_s union H_s = Vset
H_s = ordered complement of G_s

For EVEN V:

|G_s| = V / 2
S(V) = C(V, V/2)

For ODD V:

first include generator subsets of size floor(V/2), then include generator
subsets of size ceil(V/2), so:

S(V) = 2 * C(V, floor(V/2))

Required examples:

V=6 -> S=20
V=5 -> S=20
V=2 -> S=2

No dataset-specific action count may be manually tuned.

======================================================================
6. ACTION ORDERING CONTRACT
======================================================================

Action identity and action order are scientific quantities and must not be
silently reordered.

For EVEN V, enumerate:

itertools.combinations(range(V), V // 2)

in Python lexicographic combination order. For each G, H is the ordered
complement of G.

For ODD V, the FIRST block is:

itertools.combinations(range(V), floor(V/2))

in lexicographic order. The SECOND block is:

itertools.combinations(range(V), ceil(V/2))

in lexicographic order. For each G, H is its ordered complement.

The resulting ordered action list must be deterministic and stored/audited as
part of every generic-contract reference.

9. EVEN-V CORRUPTION CONTRACT
======================================================================

For EVEN V, every sample has exactly:

k = V / 2

corrupted views.

Therefore:

- Caltech V=6 -> exactly 3 views per sample
- BDGP V=2 -> exactly 1 view per sample

The future even-V generic corruption-mask constructor must be bitwise/backward
compatible with the existing frozen algorithm. For Caltech, identical weak-
quality seed, np.random.RandomState semantics, RNG call order, sample
permutation, view permutation, mask, and mask SHA256 are mandatory.

======================================================================
10. ODD-V 50-PERCENT CORRUPTION CONTRACT
======================================================================

For ODD V define:

B = floor(N * V / 2)
k_low = floor(V/2)
k_high = ceil(V/2)
n_high = B - N * k_low

The first n_high samples in deterministic shuffled-sample rank receive k_high
corrupted views. The remaining N-n_high receive k_low corrupted views.

The total corruption count must equal B. If N*V is even, the global corruption
ratio is exactly 0.5. If N*V is odd, the deterministic budget is
floor(N*V/2).

For MSRC-v1:

N=210
V=5
B=525
k_low=2
k_high=3
n_high=105

Exactly 105 samples receive 3 corrupted views and 105 receive 2. Exactly
525/1050 sample-view pairs are corrupted. A floor-only 40-percent rule and a
ceil-only 60-percent rule are forbidden.

======================================================================
11. GENERIC BALANCED MASK CONSTRUCTION
======================================================================

Future G0-A0 must preserve the balanced cyclic-mask principle and use:

rng = np.random.RandomState(seed)

with exact RNG call order:

sample_permutation = rng.permutation(N)
view_permutation = rng.permutation(V)

For shuffled sample rank r, assign the required row cardinality k_r. For odd V,
the first n_high ranks of sample_permutation receive k_high and all remaining
ranks receive k_low.

Define:

base_r = (sum of k_j for all shuffled ranks j < r) mod V

Select k_r consecutive cyclic positions from the one fixed view_permutation.

The construction must guarantee:

- exact per-row corruption cardinality
- exact total corruption budget
- per-view corrupted-pair counts differing by at most 1
- deterministic output

For even V all k_r=k, so base_r=(r*k) mod V. This must reduce exactly to the
legacy algorithm and preserve the frozen Caltech mask bitwise.
